# 古建筑平台

一个展示中国古建筑文化的交互式平台，包含建筑介绍和闯关游戏功能。

## 项目结构

- `src/` - 源代码目录
  - `components/` - 组件目录
  - `App.jsx` - 应用主组件
  - `main.jsx` - 应用入口
- `public/` - 静态资源目录
- `dist/` - 构建输出目录

## 技术栈

- React 18
- Vite
- Tailwind CSS
- React Router

## 安装和运行

1. 克隆仓库
2. 安装依赖：`npm install`
3. 开发模式运行：`npm run dev`
4. 构建项目：`npm run build`

## 部署

项目使用 GitHub Pages 部署。
